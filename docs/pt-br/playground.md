Escolha uma função, edite os argumentos e execute. O playground importa a última versão publicada por um CDN, o mesmo código que o `npm install` entrega, então nada aqui é simulado. Os argumentos são lidos como JSON, uma entrada por argumento: `["123.456.789-09"]` chama a função com uma string, `["Q0SLFMBD7VX439", { "version": 2 }]` com uma string e um objeto de opções. Pressione Ctrl+Enter (Cmd+Enter no macOS) na caixa de argumentos para executar de novo.
